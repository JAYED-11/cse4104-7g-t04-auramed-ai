# AuraMed AI

### Multimodal Patient Triage and Retrieval-Augmented Generation (RAG) Symptom Analyzer

## Course Information
- Course: CSE4104
- Team: CSE4104-7G-T05
- Section: 7G

## Project Overview
AuraMed AI is an AI-powered health information and preliminary patient triage system. It accepts text, voice, images and medical reports to provide preliminary health information and urgency guidance.

It is designed to support users, not replace professional medical diagnosis or treatment.

## Technology Stack
- Frontend: Flutter
- Backend: Python FastAPI
- Database: Supabase PostgreSQL
- Vector Search: pgvector
- AI: Google Gemini
- Containerization: Docker

## Planned Features
- Text-based symptom input
- Voice input
- Image and medical report upload
- AI-powered RAG responses with source references
- Preliminary urgency classification
- Bengali and English support
- Health profile and analysis history

## Repository Structure
- `frontend/` — Flutter mobile application
- `backend/` — FastAPI backend
- `database/` — Database design and scripts
- `scripts/` — Automation and ingestion scripts
- `docs/` — Project documentation

## Disclaimer
AuraMed AI provides preliminary health information and urgency guidance. It does not provide definitive medical diagnoses or replace qualified healthcare professionals.
